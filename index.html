Режим достижений
«Скрыть» убирает пункт из меню «Ещё», карточку в прогрессе и всплывающие уведомления. «Без уведомлений» — прогресс считается тихо, без toast 🏅.
Закрывать предыдущую карточку при открытии новой
Вкл — открыта только одна карточка «с подробностями» за раз, старая закрывается сама. Выкл — можно открыть сразу много карточек, каждую нужно закрывать вручную нажатием по ней.
Максимум одновременно открытых карточек
Работает только при выключенной опции выше. Как только откроется карточка сверх лимита — самая первая из открытых закроется автоматически.
Когда сбрасывать открытые карточки
Работает только при выключенной опции «Закрывать предыдущую…» выше. Определяет, когда все открытые карточки автоматически сворачиваются обратно.

Загруженные суры сохраняются для чтения без интернета.

⚡ Быстрые пресеты
Применяют сразу несколько настроек одной кнопкой, вместо ручной настройки по отдельности. Нажмите на карточку пресета ниже — что именно изменится (с текущего значения на новое); кнопка «Применить» внутри неё применяет сразу, без разворачивания. Можно сохранить и свой набор настроек как пресет — кнопка снизу. После применения любой пункт можно донастроить вручную в других вкладках.
