# Журнал расхода лимита (Claude)

Как вести: после каждого скриншота лимита — строка «что сделано между замерами → сколько ушло».
Цифры — прирост с прошлого замера. Первую неделю только записывать, выводы не делать (решение пользователя). Модель и усилие указывать, они влияют на расход.

Заметка: к концу 6.96 контекст чата был 473k из 1M токенов (47%). (Чем длиннее чат, тем дороже каждый следующий шаг.)

**Правила журнала (для всех чатов):**
- Только ДОБАВЛЯТЬ новые строки в самый конец файла. Старые строки не править и не переставлять (решение владельца 2026-11-21).
- Строка = дата · модель · что сделано между замерами · прирост «Сессия» · прирост «Неделя». Замер владельца приходит как «контекст сессия неделя» (три числа).
- Если у прошлой строки стоит «?» — её прирост учтён в ближайшей строке ниже, где есть цифры.
- Если при слиянии веток конфликт в этом файле — оставить строки обеих сторон.
